# qbitos-algorithms

Production-grade algorithmic primitives for QbitOS.

## Modules

| Module | Description |
|--------|-------------|
| `astar` | A* pathfinding search |
| `dijkstra` | Dijkstra shortest-path |
| `hnsw` | Hierarchical Navigable Small World index |
| `cuckoo` | Cuckoo filter (probabilistic set membership) |
| `hll_plus` | HyperLogLog++ (cardinality estimation) |
| `skip_list` | Skip list (ordered map with O(log n) operations) |
| `bloom` | Bloom filter |
| `count_min` | Count-Min sketch |
| `robin_hood` | Robin Hood hash map (open-addressing with displacement stealing) |
| `kd_tree` | K-d tree (spatial indexing) |
| `trie` | Prefix tree |
| `levenshtein` | Levenshtein edit distance |
| `lru_cache` | LRU cache |
| `lfu_cache` | LFU cache |
| `rle` | Run-length encoding |
| `topk` | Top-K tracker |
| `quickselect` | Quickselect (k-th smallest element) |
| `graph` | Connected components, topological sort, SCC |
| `disjoint_set` | Union-Find with path compression |
| `consistent_hash` | Consistent hashing ring |
